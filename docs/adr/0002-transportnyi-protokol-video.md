# ADR-0002. Транспортний протокол для відеопотоку

## Статус

Прийнято, 2026-09-16

## Контекст

Потрібно передавати відео у двох різних напрямках з різними вимогами:
(а) від IP-камери до сервісу прийому — стандартний протокол камер
спостереження, стабільність важливіша за зручність у браузері;
(б) від сервера до веб-консолі оператора (FR-01–FR-03) — низька затримка
живого перегляду та відтворення кліпів прямо в браузері без додаткового
плагіна.

## Варіанти

1. **RTSP/RTP наскрізно, включно з браузером оператора.** Це нативний
   протокол більшості IP-камер (ONVIF), низька затримка, але сучасні
   браузери не підтримують RTSP нативно — знадобився б плагін або
   встановлюваний клієнт, що суперечить вимозі простої веб-консолі.
2. **HLS наскрізно.** Простий у реалізації (звичайний HTTP, сегменти
   вкладаються в CDN/кеш), але типова затримка 6–30 с — неприпустимо для
   бюджету L_заг = 2000 мс з NFR-01.
3. **RTSP від камери до сервера + релей у WebRTC (або MSE через
   WebSocket) від сервера до браузера оператора.** Камера працює у
   звичному для неї режимі, а оператор отримує потік у браузері з
   затримкою до ~1 с.

## Рішення

Обрано варіант 3. Сервіс прийому відео (Ingest) приймає RTSP/RTP від камер
без змін у їхній конфігурації; окремий релей-компонент перекодовує/ретранслює
потік у WebRTC для живого перегляду в веб-консолі оператора. Короткі кліпи
тривог (FR-02) віддаються як звичайні MP4-файли через HTTPS, де затримка в
кілька секунд некритична.

## Наслідки

+ Камери підключаються без нестандартної прошивки чи налаштувань —
  сумісність із ONVIF-обладнанням (інтерес IT-інтегратора) збережена.
+ Оператор дивиться живе відео прямо в браузері без плагінів, затримка
  живого перегляду не заважає виконанню NFR-01.
− Потрібен додатковий релей-компонент (сигналізація WebRTC, можливо
  TURN-сервер для NAT), що збільшує кількість складників системи
  (див. компонентне подання).
− Два різні протоколи в системі (RTSP усередині, WebRTC назовні) означають
  два набори залежностей і два місця для налагодження мережевих проблем.
